# Pulse Notes

Pulse Notes document significant changes in the design and development of Pulse. Each entry covers a milestone, the evidence behind it, and any resulting changes to the architecture or research priorities.

Notes are written when there is enough progress to describe a meaningful result. They are not intended to reproduce the commit history or detailed engineering test logs.

## Index

- [2026-10-07 — From concept to working pre-alpha](2026-10-07-from-concept-to-working-pre-alpha.md)

## Editorial scope

An entry may cover several weeks of development. Failed experiments are included when their results affected the design or identified a problem that remains unresolved.

Detailed test identifiers, local environments, raw traces, and routine implementation changes stay in the private engineering record. Dates indicate when a note was written; retrospective entries are identified as such.

The index is maintained in reverse chronological order.
